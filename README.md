# MICU HANDOVER — চালু করার নির্দেশিকা

Firebase ছাড়া খুললে অ্যাপ **ডেমো মোডে** চলে। তখন তথ্য শুধু ওই ডিভাইসে থাকে, আর রোগীরা বানানো উদাহরণ।
দলের সবাই মিলে ব্যবহার করতে নিচের ধাপগুলো একবার করতে হবে।

## ১. Firebase প্রকল্প তৈরি
1. https://console.firebase.google.com → **Add project** → নাম দিন (যেমন `icu-handover`)।
2. **Build → Authentication → Get started → Email/Password** চালু করুন → Save।
3. **Build → Firestore Database → Create database**। লোকেশন **asia-south1 (Mumbai)** দিন, **Production mode** বেছে নিন।
4. Firestore-এর **Rules** ট্যাবে `firestore.rules` ফাইলের পুরো লেখা বসিয়ে **Publish** চাপুন।

## ২. config.js ঠিক করা
1. Firebase-এ **Project settings (⚙) → Your apps → Web (</>)** → একটা নাম দিয়ে Register করুন।
2. যে `firebaseConfig` দেখাবে, তার মানগুলো `config.js`-এর `firebase: { … }` অংশে বসান।
3. `appName` চাইলে বদলান। অ্যাডমিন ইমেইল `config.js` আর `firestore.rules` দুই জায়গায় একই থাকতে হবে।

## ৩. GitHub-এ তোলা
1. নতুন repository খুলে এই ফোল্ডারের **সব ফাইল** (`lib`, `icons` ফোল্ডারসহ) আপলোড করুন।
2. **Settings → Pages → Branch: main / root** → Save।
3. Firebase-এ **Authentication → Settings → Authorized domains → Add domain** → `আপনার-নাম.github.io` যোগ করুন।

## ৪. প্রথমবার ঢোকা
1. অ্যাপ খুলে **সবার আগে নিজের অ্যাডমিন ইমেইল দিয়ে** Create account করুন।
2. ইমেইলে আসা যাচাইয়ের লিংকে চাপুন, তারপর অ্যাপে **I have verified** চাপুন।
3. এরপর মেডিকেল অফিসাররা নিজেরাই Create account করবেন।
4. আপনি **Settings → Users** থেকে প্রত্যেককে একবার **Approve** করবেন। এরপর তাঁরা ইমেইল-পাসওয়ার্ড দিয়ে যেকোনো সময় ঢুকতে পারবেন।
5. **Settings → Lists** থেকে সবার জন্য ঠিক করে দিন: বেড (যোগ, বদল, মুছে ফেলা, ওপরে-নিচে সরানো), কনসালট্যান্টদের নাম (রেফারেল ডাক্তারের ঘরেও এগুলোই আসে), "From" (ER, WARD/CABIN), রোগনির্ণয়ের ট্যাগ, অ্যান্টিবায়োটিকের ট্যাগ, অন্য ওষুধের ট্যাগ। রোগীর পাতায় এগুলো বোতাম হয়ে আসে, একবার চাপলেই লেখা হয়ে যায়।

## প্রতিদিনের ব্যবহার
- হ্যান্ডওভার মানে "এই মুহূর্তে ICU-তে যারা আছে"। যখনই দরকার **New handover** চাপুন, ১২ ঘণ্টা পরে হোক বা ২৪ ঘণ্টা পরে। অ্যাপ তারিখ আর সময় রেখে দেয়, একই দিনে একাধিক হ্যান্ডওভারও চলে।
- নতুন হ্যান্ডওভারে আগের হ্যান্ডওভারের রোগীরা টিক দেওয়া অবস্থায় আসেন। যিনি চলে গেছেন তাঁর টিক তুলে কারণ (Discharged / Shifted to ward / DAMA / Death / Transferred) দিন। তিনি নতুন শিটে আসবেন না, তবে তাঁর সব তথ্য থেকে যাবে।
- **মাঝে এসে চলে যাওয়া রোগী** (যেমন সকাল ৮টায় এসে দুপুরে মারা গেছেন): নতুন হ্যান্ডওভারের সময় "Came and left in between" অংশে, অথবা যেকোনো সময় "+" → "Came and left before the next handover" দিয়ে লিখুন। এরা মূল শিটে আসেন না, কিন্তু রিপোর্ট, মৃত্যুর হিসাব আর স্টাডিতে থাকেন। চাইলে Settings → Print থেকে প্রিন্টের নিচে ছোট তালিকা হিসেবেও আনা যায়।
- তারিখে চাপলে মাস অনুযায়ী সব হ্যান্ডওভারের তালিকা আসে; যেকোনোটায় চাপলে খুলে যায়।
- মেনু (⋮) → **Download Word (DOCX)** বা **Print / Save as PDF**।

## Microsoft Word-এর সঙ্গে
- DOCX মানেই Microsoft Word-এর ফাইল। অ্যাপ থেকে নামানো ফাইল Word-এ খুলবে, আপনার শিটের মতোই A4 আড়াআড়ি টেবিল, প্রতিটি পাতার ওপরে ডাক্তারদের নাম আর তারিখ। ১২ জন রোগী হলে ৩–৪ পাতা হবে, যেমন এখন হয়।
- কেউ অ্যাপ ব্যবহার না করে কম্পিউটারে Word-এ শিট বানালেও চলবে। মেনু → **Import edited DOCX** দিয়ে ফাইলটা তুললে অ্যাপ তারিখ, ডাক্তারদের নাম আর প্রতিটি রোগী বুঝে নিয়ে তথ্যভান্ডারে রাখবে (আর Drive-এ জমা হবে)।
- শর্ত একটাই: টেবিলের কলামের ক্রম আপনার এখনকার শিটের মতো থাকতে হবে। ফাইলটা পুরোনো `.doc` হলে Word-এ **Save As → Word Document (.docx)** করে নিন।

## ৫. Google Drive-এ জমা রাখা (একবার, ল্যাপটপ থেকে)
প্রতিটি হ্যান্ডওভার আপনার Drive-এ বছর ও মাস অনুযায়ী ফোল্ডারে DOCX আর JSON হিসেবে জমা হবে (যেমন `MICU HANDOVER Archive / 2026 / 10-October / MICU_Handover_2026-10-23_0740.docx`), আর প্রতিটি রোগীর তথ্য একটা Google Sheet-এ ("MICU HANDOVER Database") এক সারি করে যোগ হবে। পরে এখান থেকেই তথ্য বের করবেন।
1. যে Google অ্যাকাউন্টের Drive-এ রাখতে চান, সেটায় ঢুকে https://script.google.com → **New project**।
2. `drive/Code.gs` ফাইলের পুরো লেখা বসান। ওপরে `SECRET_KEY`-এ নিজের একটা লম্বা গোপন লেখা দিন → Save।
3. **Deploy → New deployment → Select type: Web app**। *Execute as*: **Me**, *Who has access*: **Anyone** → Deploy → অনুমতিগুলো Allow করুন।
4. যে **Web app URL** দেখাবে সেটা কপি করুন।
5. অ্যাপে **Settings → Drive**-এ URL আর একই গোপন লেখা বসিয়ে **Test connection** → **Save**।

"Save past days automatically" চালু থাকলে নতুন হ্যান্ডওভার শুরু হওয়ার পর যে প্রথম অ্যাপ খুলবেন, তাঁর ফোন থেকে আগের সাত দিনের বদলানো হ্যান্ডওভারগুলো নিজে থেকে Drive-এ চলে যাবে। মেনু থেকে যেকোনো সময় **Save to Google Drive now** চাপা যায়।
Code.gs পরে বদলালে **Deploy → Manage deployments → Edit → New version** দিতে হবে, তাহলে URL একই থাকবে।

## অন্যান্য সুবিধা
- **Import edited DOCX** (মেনু ⋮): কম্পিউটারে সম্পাদনা করা বা হোয়াটসঅ্যাপে পাওয়া শিট তুললে অ্যাপ নাম ও বেড মিলিয়ে রোগীদের হালনাগাদ করে। সংরক্ষণের আগে কী বদলাবে দেখায়। টেবিলের কলামের ক্রম ঠিক রাখতে হবে; পুরোনো .doc ফাইল হলে Word-এ .docx হিসেবে সেভ করে নিন।
- **Search all days**: সব সময়ের রোগী (নাম, UHID, রোগনির্ণয়), অথবা নির্দিষ্ট সময়ের মধ্যে লেখা যেকোনো শব্দ।
- **Changes on this handover**: কে কখন কী বদলেছেন। রোগীর কার্ড খুললে নিচে ওই রোগীর ইতিহাস আর আগের দিনগুলোর লিংক।
- **Reports and data**: রোগীর সংখ্যা, ফলাফল, গড় ICU-তে থাকার দিন; Excel-এর জন্য CSV।
- **দুই ডিভাইস**: প্রত্যেক মেডিকেল অফিসার সর্বোচ্চ দুটি ডিভাইসে ঢুকতে পারবেন (অ্যাডমিনের সীমা নেই)। তৃতীয় ডিভাইসে ঢুকলে আগের একটা নিজেই সরাতে পারবেন। অ্যাডমিন **Settings → Users → Clear devices** দিয়েও খালি করতে পারেন। সংখ্যা বদলাতে `config.js`-এ `maxDevices` দিন।
- কার্ডে "ENSURE … REF" লেখা থাকলে লাল চিহ্ন দিয়ে আলাদা দেখায়।

## Study অংশ (শুধু অ্যাডমিন)
মেনু (⋮) → **Study**। হ্যান্ডওভারের সঙ্গে এর কোনো সম্পর্ক নেই; প্রিন্ট বা DOCX-এ কখনো আসে না। রোগীর নাম, বয়স, UHID, রোগনির্ণয়, ভর্তির তারিখ আর ফলাফল হ্যান্ডওভার থেকে নিজে থেকে আসে।
- **Patients**: রোগী বেছে চারটা অংশ:
  - *Investigations*: CRP, PCT, CBC, Troponin I, BNP, CPK, Urine R/E, Creatinine, Urea, Electrolytes, DIC, ABG, LFT, TFT। যত খুশি তারিখ ও সময়ের কলাম। স্বাভাবিক সীমার বাইরে হলে নিজে থেকে লাল/নীল, চাইলে নিজে রং দিন। ICU-র কত নম্বর দিন তাও দেখায়।
  - *Serology*: Dengue RT-PCR, NS1, IgM, Respiratory panel PCR, BioFire (blood, tracheal, অন্য), COVID, CMV, HIV, HBsAg, Anti-HCV।
  - *Cultures*: Blood, Urine, Tracheal, Wound ইত্যাদি; জীবাণু, কলোনি, আর প্রতিটি অ্যান্টিবায়োটিকের S / I / R।
  - *Antibiotics*: কোন ওষুধ কবে শুরু, কবে বন্ধ, কেন বদল। নিজে থেকে হিসাব করে: কতবার বদলানো হয়েছে, কতগুলো বদল কালচার রিপোর্ট আসার আগে, মোট কত দিন। "What the handovers say" চাপলে হ্যান্ডওভারে লেখা ওষুধগুলো দিন অনুযায়ী দেখায়।
- **CPR register**: কোথায় অ্যারেস্ট (ICU / Emergency / Ward / OT…), রোগী কোথা থেকে এসেছেন, তারিখ, সময়, কত মিনিট CPR, ROSC হয়েছে কি না, শেষ ফল (ICU থেকে জীবিত বের হয়েছেন / মারা গেছেন / DAMA / এখনো ICU-তে)। সময় অনুযায়ী হিসাব আর জায়গা অনুযায়ী ভাগ।
- **Outcomes**: যেকোনো সময়ের মধ্যে কতজন মারা গেছেন, DAMA, ছুটি, ওয়ার্ডে গেছেন, স্থানান্তর, এখনো ICU-তে; মৃত্যুর হার, গড় ICU-তে থাকার দিন, নামের তালিকা, CSV।
- **My studies**: নিজের স্টাডি বানান, কী কী লিখবেন ঠিক করুন (সংখ্যা, হ্যাঁ/না, তালিকা, তারিখ, লেখা), রোগী যোগ করুন, এক ক্লিকে CSV।
- **Test lists**: পরীক্ষার নাম, একক (unit), স্বাভাবিক সীমা, সেরোলজি, জীবাণু আর অ্যান্টিবায়োটিকের তালিকা আপনার হাসপাতালের মতো বদলে নিন।
- সব CSV নাম আর UHID বাদ দিয়ে শুধু কোড দিয়েও নামানো যায়। কোডগুলো স্থির থাকে, তাই আলাদা দিনে নামানো ফাইলও মেলানো যায়।
- **অন্যদের অনুমতি**: Settings → Users-এ প্রত্যেকের পাশে "Study: No access / Can view / Can edit"। এখন কাউকে না দিলে শুধু আপনিই দেখবেন।
